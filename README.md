Supply Prescript

📌 Project Overview

Supply Prescript is a data-driven supply chain management and prediction project designed to analyze shipment, supplier, product, and customer data and support better supply chain decisions.

The project combines SQL, Python, Machine Learning, and data analysis to understand supply chain performance, identify risks, and generate useful predictions and recommendations.

🎯 Objectives

- Analyze supply chain and shipment data.
- Manage customers, products, suppliers, and shipments.
- Track shipment status and delivery performance.
- Identify potential supply chain risks.
- Use Machine Learning for predictions.
- Generate recommendations for better supply chain decisions.
- Store and manage project data using SQL.

🚀 How to Run

1. Clone the repository

git clone <your-github-repository-url>
cd Supply-Prescript

2. Install required packages

pip install -r requirements.txt

3. Set up the database

Open the SQL files and execute them in MySQL to create the required database and tables.

4. Run the Python application

python main.py
